Banking Microservices Application

Event-driven digital banking platform

Open live app ↗ Read the full README ↗

A six-service banking system I built to go deep on event-driven microservices — account management, money transfers, fraud checks, Razorpay payment capture, and notifications, all coordinated through Kafka instead of tight synchronous coupling. Each service owns its own PostgreSQL database; Redis handles short-lived OTP verification.

Java 17 / Spring Boot 3 Apache Kafka PostgreSQL Redis OpenFeign Razorpay SDK Docker Compose API Gateway
Synchronous (REST / Feign) Asynchronous (Kafka event) 
# transfer money between accounts
curl -X POST http://localhost:8082/api/v1/transactions/transfer \
  -H "Content-Type: application/json" \
  -d '{
    "senderAccountNumber": "123456789012",
    "receiverAccountNumber": "987654321098",
    "amount": 1000,
    "currency": "INR"
  }'

# if flagged as suspicious, verify with the OTP sent via notification-service
curl -X POST "http://localhost:8082/api/v1/transactions/{id}/verify?otp=123456"

A transfer that looks risky triggers an OTP flow automatically: fraud-detection-service flags it, transaction-service generates a 6-digit code with a 5-minute expiry in Redis, and the transfer only completes once it's verified — otherwise the sender's account is flagged and the transaction refunded.
